# CalVant — TPRM Module User Guide

*Version 1.1 | July 2026*

## 1. Introduction 

The Vendor Module in CalVant helps you assess, monitor, and manage the risk posed by thirdparty vendors as part of your Third Party Risk Assessment program. It lets you build vendor assessments, send them to vendors, and track each response from submission through to approval. 

This guide follows the module in the order you'll actually use it. 

## 2. Accessing the Vendor Module 

After logging in to CalVant, use the left-hand navigation sidebar to move between modules. Click the Vendor icon in the sidebar to land on your Third Party Risk Assessment Dashboard. 

Vendors have their own view and access their own assigned assessments through the Vendor Assessment Portal using their vendor login. 

## 3. Manual Navigation

### 3.2 Creating a New Vendor Assessment 

CalVant uses a guided, two-step process to create and send a vendor assessment. 

From the TPRM Dashboard, click Plan TPRM under the Quick Actions Zone to open Conduct TPRM, then click New Assessment. 

![Risk Dashboard overview](/Screenshots/Vendor/2.png) 

### 3.2.1 Step 1 — Assessment Details 

![Risk Dashboard overview](/Screenshots/Vendor/3.png)

The first step captures the core details of the assessment: 

Assessment Title — a descriptive name for the assessment (e.g., Q1 2026 Vendor Security Assessment). 

Assign to Vendor — select the vendor to assess. Only vendors with TPRM module access appear in this list. If none do, CalVant shows a "No vendors found with TPRM module access" notice. 

Due Date — Required; the date by which the vendor must submit the assessment. 

Click Next: Select Questions to continue. 

### 3.2.2 Step 2 — Select Questions

![Risk Dashboard overview](/Screenshots/Vendor/4.png)

Build the assessment by choosing questions from the question bank, organized by section. 

Use Search Questions or Select All to quickly build the question set; the counter tracks your progress. 

Expand a section — such as Information Security Governance, Data Protection & Privacy, Security Controls, or Incident Management — to choose individual questions, or check the section box to select all questions in it. 

Review the summary panel (Title, Vendor, Due Date, and Questions) before sending. 

Click Submit to send the assessment to the selected vendor, or Back to revise the assessment details. 

### 3.3 Tracking Sent Assessments 

Clicking on the previous button from the lands you on the Conduct TPRM pop-up screen, which lists every assessment you've created, whether still in draft, sent, or completed. 

Use the filter chips — All, Due, Received, Completed — to narrow the list by stage. 

Click New Assessment at any time to start another vendor assessment. 

### 3.4 Vendor Assessment Portal 

Vendors complete their assigned assessments through their own portal view, which mirrors the admin dashboard but is scoped to that vendor's assessments only. The screen is organized into the same Overview Zone and Visual Representation Zone pattern as the admin dashboard, alongside an Assessments panel and a Status Guide panel. 

![Risk Dashboard overview](/Screenshots/Vendor/5.png) 

Overview Zone — A row of summary tiles showing Total, Send, Submitted, Approved, and Rejected counts for the logged-in vendor. 

Assessments panel — Lists the vendor's assessments, filterable by All, Sent, Submitted, Under_review, or Approved, so the vendor can track progress. 

Status Guide — Explains each assessment status in plain language so the vendor knows what action, if any, is required: 

Pending Answer — The admin has sent the vendor a questionnaire to fill out. 

Submitted — The vendor has submitted the assessment; the admin is reviewing it. 

Approved — The admin has approved the vendor's submission. 

Rejected — The admin has rejected the submission; the vendor should check the comments. 

With this, you've covered the full Vendor Module workflow in CalVant — from planning an assessment on the Dashboard through to the vendor completing it in their own portal. Refer back to any section as needed while managing your third-party risk program.
