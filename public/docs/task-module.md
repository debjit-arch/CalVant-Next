# CalVant — AIIA Module User Guide

*Version 1.1 | July 2026*

## 1. Introduction 

The Task Module in CalVant serves as the centralized task management workspace. Tasks created from Risk, Compliance, Policy, Audit, DPIA, AI IA, and other modules are managed here, allowing users to assign, monitor, update, and complete activities from a single location. 

This guide follows the module in the order you'll actually use it. 

## 2. Accessing the Task Module 

After logging in to CalVant, use the left-hand navigation sidebar to move between modules. Click the Task icon in the sidebar to land on your Task Dashboard. 

## 3. Manual Navigation 

## 3.1 Task Dashboard 

![Risk Dashboard overview](/Screenshots/Task/1.png)  

The Task Dashboard is your home base for centralized activity tracking. It gives you an at-a-glance summary of all tasks across your organization. 

The screen is organized into three zones: the Overview Zone, the Quick Actions Zone, and the Visual Representation Zone. 

### Overview Zone 

A row of summary tiles showing My Tasks, Reported Tasks, Orgwide Tasks, In Progress, Due Soon, Overdue, Done, and Archived Tasks counts. 

### Quick Actions Zone 

Gives one-click access to the most common tasks: 

- Manage Tasks — Browse all tasks across the organization. 

- Create Task — Launch the guided workflow to add a new task. 

### Visual Representation Zone 

- Tasks Distribution — A donut chart showing task status breakdown. 

- Monthly Task Creation Trends — A bar chart displaying new tasks created each month. 

## 3.2 Managing Tasks 

![Risk Dashboard overview](/Screenshots/Task/2.png)

![Risk Dashboard overview](/Screenshots/Task/3.png)

Clicking Manage Tasks from the dashboard opens the Action Plan screen, which displays all tracked tasks across your organization. 

The screen's Overview Zone shows summary counts for Total, In Progress, Done, Overdue, and Due Soon. Use the Assignee dropdown or Reporter selector to narrow the list. Each row lists table identifiers including #, Task name/description, Source (e.g., General, Risk), Source ID, Status, Assignee, Reporter, Priority, Created Date, Due Date, and row-level Actions (View, Edit, Archive). 

Clicking View on any task opens the detailed task view pane from the right side of the screen, allowing you to view the associated risk. From this panel, you can also add subtasks, remarks, and work logs, as well as update the task status. Any changes or updates made here will trigger notifications to the Assigner, Assignee, and Admin, ensuring that all relevant users are informed. 

![Risk Dashboard overview](/Screenshots/Task/4.png) 

Clicking the Edit option allows you to modify the task details, including the assigned department/risk owner, due date, and criticality. Any changes made to these details will also trigger email notifications to the Assigner, Assignee, and Admin. 

![Risk Dashboard overview](/Screenshots/Task/7.png) 

## 3.3 Creating a New Task 

![Risk Dashboard overview](/Screenshots/Task/6.png) 

To initiate a new task, click Create Task under the Quick Actions Zone on the dashboard or from the Action Plan screen to open the Create Task window. 

Complete the following core fields to create a new task: 

- Department — Select the department responsible for the task. 

- Type — Select the task classification (e.g., Framework Based). 

- Sub Type — Select the specific framework or sub-category. 

- Assign To — Select the user responsible for completing the task. 

- Task Description — Enter a detailed description of the activity to be performed. 

- Start Date — Select the expected start date. 

- End Date — Select the target completion due date. 

- Priority — Select Low, Medium, High, or Critical. 

- Remarks — Add any optional notes or instructions. 

Click Create Task to save and initialize the record. 

## 3.4 My Tasks & Tracking (User View) 

![Risk Dashboard overview](/Screenshots/Task/8.png) 

The My Tasks screen lists all tasks assigned directly to you for review and completion. Access it via My Tasks under Quick Actions on the dashboard. 

The screen's Overview Zone displays summary cards for Total, In Progress, Done, On Hold, and Critical tasks assigned to you, alongside filter tabs such as All, To-Do, and In Progress. Each entry details the Task ID, description summary, assignee, priority badge, start date, due date, and status indicator. 

## 3.5 Task Module Integration with Other Modules 

The Task Module is integrated with other CalVant modules, allowing activities identified during risk assessments, compliance reviews, policy management, audits, and assessments to be converted into trackable tasks. 

## 3.5.1 Risk Module 

Tasks can be created directly from the Risk Module to assign and track activities related to identified risks, including risk treatment and mitigation actions. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Risk-Module-1.png) 

Once created, the task retains its association with the relevant risk, allowing users to access the risk context while managing the task. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Risk-Module-2.png) 

## 3.5.2 Policy Module 

Tasks can also be created from the Policy Module for activities associated with policies and their implementation. The task retains the relevant policy and control information, allowing the assigned user to work on the activity while maintaining traceability to its source. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Policy-Module-1.png) 

## 3.5.2 Compliance Module 

Within the Compliance Module, tasks can be created against applicable requirements or controls where an activity requires assignment and follow-up. This allows compliance-related actions to be tracked through the centralized Task Module. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Compliance-Module-1.png) 

## 3.5.3 Audit Module 

The Task Module is also connected with the Audit Module, where corrective actions can be created from audit findings or identified nonconformities. These actions can then be assigned to responsible users, given a priority and due date, and tracked through completion. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Audit-Module-1.png) 

![Risk Dashboard overview](/Screenshots/Task/Task-from-Audit-Module-2.png)

## 3.5.4 DPIA Module 

Tasks can be generated from the DPIA Module for activities identified during a Data Protection Impact Assessment. When creating a task, the relevant DPIA assessment can be selected as the source, ensuring that the resulting action remains traceable to the assessment from which it originated. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-DPIA-Module-1.png) 

The resulting assignment can then be managed through the Task Module, where the responsible department or risk owner, due date, and instructions can be maintained. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-DPIA-Module-2.png)

## 3.5.5 AI Impact Assessment (AI IA) Module 

The Task Module is also integrated with the AI Impact Assessment (AI IA) Module. Within an AI Impact Assessment, risk owners can be assigned to the relevant departments for the assessment. This establishes the responsible users who can subsequently be associated with activities and actions arising from the AI assessment. 

![Risk Dashboard overview](/Screenshots/Task/Task-from-AIIA-Module-1.png) 

Once an action is identified from the AI Impact Assessment, it can be converted into a task and assigned to the appropriate user. The task can then be managed through the Task Module, where its priority, start date, due date, status, and other task details can be tracked. This maintains traceability between the AI Impact Assessment and the action required to address the identified activity or requirement. 

With this, you've covered the full Task Module workflow in CalVant—from centralized dashboard tracking and task creation to execution, status updates, and reporting. Refer back to any section as needed while managing your compliance action plans.
