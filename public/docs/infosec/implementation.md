# **Implementation**

As the next step in CalVant, following completion of the Design & Documentation Phase, you need to move to the Implementation Phase — turning the documented ISO/IEC 27001 requirements and controls into actionable and operational activities for your teams.

The 'Tasks' module serves as the central command centre for this phase. Use it to distribute implementation activities to your teams, assign responsibility, define timelines and priorities, track progress, and maintain the activity trail as each item is completed. Where an implementation activity is documentation-related — such as creating, updating, reviewing, or maintaining a document or ACL — raise it from the 'Policies' module instead, so that the task remains linked to the relevant policy and control.

For this, begin by visiting the [**"Tasks"**](/help-center/task-module) module of Calvant.

## Complete the following tasks:

### 1. Access the Task Dashboard

**Tasks → Task Dashboard**

**A.** From the main sidebar, click **'Tasks'** to open the Task Dashboard.

The Task Dashboard is your starting point for managing the implementation plan. It gives you an at-a-glance summary of all tasks across your organization and provides the actions you need to create and manage implementation activities.

The screen is organized into three zones: the Overview Zone, the Quick Actions Zone, and the Visual Representation Zone.

#### Overview Zone

A row of summary tiles showing **'My Tasks'**, **'Reported Tasks'**, **'Org-wide Tasks'**, **'In Progress'**, **'Due Soon'**, **'Overdue'**, **'Done'**, and **'Archived Tasks'** counts. These summary indicators give you an immediate view of the current state of implementation activities across the organization.

#### Quick Actions Zone

Gives one-click access to the most common task actions:

- **'Manage Tasks'** — Browse and manage all tasks across the organization.
- **'Create Task'** — Launch the guided workflow to add a new task.

#### Visual Representation Zone

- **'Tasks Distribution'** — A donut chart showing the task status breakdown.
- **'Monthly Task Creation Trends'** — A bar chart displaying new tasks created each month.

### 2. Create a Task

**Tasks → Task Dashboard → Create Task**

#### 2A. Complete the core fields

**A.** From the Task Dashboard, click **'Create Task'** under the Quick Actions Zone to open the Create Task window. This is where you define the implementation activity, identify who is responsible for completing it, and establish the timeline within which it needs to be completed.

Complete the following core fields:

- **'Department'** — Select the department responsible for the task.
- **'Type'** — Select the task classification as **'Framework Based'**.
- **'Sub Type'** — Select the specific framework as **'ISO 27001:2022'**. This is how the task maps itself to the selected framework.
- **'Assign To'** — Select the user responsible for completing the task.
- **'Task Description'** — Enter a detailed description of the activity to be performed.
- **'Start Date'** — Select the expected start date.
- **'End Date'** — Select the target completion due date.
- **'Priority'** — Select **'Low'**, **'Medium'**, **'High'**, or **'Critical'**.
- **'Remarks'** — Add any optional notes or instructions.

Click **'Create Task'** to save and initialize the record.

The task then becomes part of the organization's implementation action plan, allowing you to review the activity alongside other implementation tasks and monitor its progress.

### 3. Manage and Track the Action Plan

#### 3A. Open the Action Plan

**Tasks → Manage Tasks**

**A.** From the Task Dashboard, click **'Manage Tasks'** to open the **'Action Plan'** screen.

The Action Plan provides the central view of all tracked implementation activities across your organization. This is where you can review the tasks you have created, identify their current status, and monitor activities that require attention.

The Overview Zone shows summary counts for **'Total'**, **'In Progress'**, **'Done'**, **'Overdue'**, and **'Due Soon'**.

Use the **'Assignee'** dropdown or **'Reporter'** selector to narrow the list when you need to review activities assigned to a particular user or reported by a particular user

### 4. View, Update, and Close Out a Task

#### 4A. Open the task detail view

**Tasks → Manage Tasks → View**

**A.** From the Action Plan, click **'View'** on the relevant task to open the detailed task view pane on the right side of the screen.

The detailed view allows you to review the task and, where applicable, access the associated risk or source record. As the implementation activity progresses, use this view to maintain the task's progress and activity trail.

From this panel, you can add **'Subtasks'**, **'Remarks'**, and **'Work Log'** entries and update the task **'Status'** as work progresses.

Use the Remarks and Work Log entries to maintain the relevant progress and completion trail for the implementation activity.

Any changes or updates made here trigger email notifications to the **'Assigner'**, **'Assignee'**, and **'Admin'**, ensuring that the relevant users and stakeholders remain informed of changes to the implementation activity.

Any changes made here also trigger email notifications to the **'Assigner'**, **'Assignee'**, and **'Admin'**.

#### 6A. Open My Tasks

**Tasks → My Tasks**

**A.** From the Task Dashboard, click **'My Tasks'** under Quick Actions to view all tasks assigned directly to you.

The Overview Zone shows summary cards for **'Total'**, **'In Progress'**, **'Done'**, **'On Hold'**, and **'Critical'** tasks, alongside filter tabs such as **'All'**, **'To-Do'**, and **'In Progress'**.

The above workflow covers the standard process of creating an implementation activity directly from the Task Module. However, implementation activities do not always originate in the Task Module itself.

Activities identified during risk assessment and policy management can also require implementation or follow-up action. Instead of creating these activities separately, CalVant allows tasks to be raised from their respective source modules and then managed centrally through the Task Module.

This allows the original source and its associated context to remain connected to the resulting implementation task.

### 7. Track Tasks Originating from Other Modules

The Task Module is integrated with all the other CalVant modules; for this phase of ISO 27001, it allows activities identified during risk assessments, policy management, and compliance reviews to be converted into trackable tasks without leaving their source screen.

Once created, these tasks roll up into the central Action Plan for tracking and management.

#### 7.1. Risk Module

**Risks → New Risk → Task Management → Add Task**

**A.** When an implementation activity arises from an identified risk, open the relevant risk and navigate to the **'Task Management'** step.

Under **'Action Plan'**, click **'Add Task'** to raise a mitigation task for that risk.

_Figure 8: Risk Module — Action Plan and the Add Task button, within Task Management._

**B.** Complete **'Department'**, **'Assign To'**, **'Task Description'**, **'Priority'**, **'Start Date'**, and **'End Date'**, then click **'Save Task'**.

Once created, the task retains its association with the relevant risk. This allows the responsible user to work on the implementation activity while retaining access to the risk context when the task is subsequently managed from the Task Module.

#### 7.2. Policy Module

**Policies → Master List of Documents → Add Task**

Where the implementation activity involves creating, updating, or maintaining controlled documentation, use the Policy Module to raise the task directly against the relevant policy and control.

**A.** From the **'Master List of Documents'**, locate the applicable policy and click **'Add Task'** on the relevant policy row to open the **'Create Task'** panel.

The task is pre-filled with the policy name and control reference. Complete **'Department'**, **'Assign To'**, **'Task Description'**, **'Start Date'**, **'End Date'**, **'Priority'**, and **'Remarks'**, then click **'Create Task'**.

The task retains the source policy and control, keeping documentation-linked implementation activities — such as maintaining a document or an ACL — traceable back to the relevant control.

Once the task has been created from the Policy Module, it can be managed and tracked through the central Task Module in the same way as other implementation activities.

#### 7.3. Compliance Module

**Compliances → Detailed View → Add Task**

Where an implementation or follow-up activity is identified against an applicable compliance requirement or control, it can be converted into a task directly from the Compliance Module.

**A.** Against the applicable requirement or control, click **'Add Task'** to open the **'Create Corrective Action Task'** window.

Complete the **'Description'**, **'Assign To'**, **'Priority'**, **'Start Date'**, and **'Due Date'**, then click **'Create Task'**.

The resulting task can then be tracked through the centralized Task Module, allowing the compliance-related activity to remain connected to the requirement from which it originated.
